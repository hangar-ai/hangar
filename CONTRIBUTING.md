# Contributing

HangarAI's source code is not public, so this repository takes no pull requests.

What helps most: [bug reports and ideas](https://github.com/hangar-ai/hangar/issues/new/choose),
with your HangarAI version (Settings › About) and your system, and the
[Discord](https://discord.gg/hangarai). Security issues go through [SECURITY.md](SECURITY.md).
Everyone here follows the [code of conduct](CODE_OF_CONDUCT.md).
